## grounding: 動画要約（Gemini API動画理解、直接引用あり）

このプロジェクトで初めて使った、第3のgroundingティア。既存の2ティアとの違い:

- **quote**（例: FPRL）: 本文（テキスト）そのものに直接あたれる。
- **paraphrase・要検証**（例: 野田修一氏の動画）: 人間（ユーザーや第三者）が
  書いた要約を経由しており、要約者の解釈・省略が入っている。
- **動画要約（本ティア）**: Gemini API（`gemini-3.6-flash`、
  `mediaResolution: low`）に動画URLを直接渡し、Geminiが実際に動画を
  視聴して生成した要約。人間の解釈を介さない分paraphraseより一段階
  グラウンディングが強いが、逐語文字起こし（quoteティアに格上げ可能）
  ではないため、Gemini自身の要約時の解釈・省略は残る。動画中の「重要な
  一文」として引用されている部分は、Geminiが実際の音声から抜き出した
  ものであり、改めて逐語文字起こしすれば`quote`ティアに格上げできる
  （手法は`cases/`の野田さん動画の逐語文字起こしと同じ）。

再現手順: `docs/case-study`または過去のセッションログ参照。要約プロンプトは
「論旨の構成（導入→展開→結論）が分かるように、引用研究・事例・重要な一文を
含めて要約」。
