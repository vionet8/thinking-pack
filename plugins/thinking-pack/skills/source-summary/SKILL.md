# 外から集めた知見をまとめる

## 決まり

1. **出典の段階を書く。**
   - **quote**: 原文どおりの引用（短く）
   - **paraphrase**: 言い換え（要検証）
   - **動画要約**: AIが動画を要約したもの（事実として扱う前に確かめる）
2. **丸写ししない。** 文字起こしや本文を全部載せない。要点を自分の言葉で再構成し、
   引用は短く必要な箇所だけにする（著作権のため）。
3. **主張と根拠を分ける。** 話し手の主張、その根拠、根拠の確かさ（伝聞・数字の出典の有無）を分ける。
4. **本人の関心とのつながりを一言添える。** 考え方の核（`thinking-core`）の、どの考えに関係しそうか。
5. **有料のAPI（Geminiなど）で取りに行く前に、何をするかと費用の見込みを伝えて了承をもらう。**

## 形

```
## （題）
URL / 出典:
grounding: （quote / paraphrase / 動画要約 のどれか、と誰が要約したか）

### 要点
- …

### 主張と根拠
- 主張: … / 根拠: …（確かさ: …）

### 本人の関心とのつながり
- …
```

## 保存先

- **本人の知識リポジトリ（`thinking-framework/sources/` がある場所）で作業しているとき**:
  動画は `thinking-framework/sources/`（チャンネルごとのフォルダ、なければ `misc-videos.md`）に保存する。
- **それ以外（職場など）**: 返事に載せるだけにし、家に持ち帰る場合は丸ごとコピーできる形にする。
