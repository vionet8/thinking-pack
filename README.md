# thinking-pack

ある個人の「考え方」と「集めた知見」を、どのClaudeからでも検索して使えるように置いた公開リポジトリ。
非公開の作業用リポジトリから自動で作られる（ここを直接編集しない）。

## Claudeへ: このリポジトリの使い方

1. 最初に [CORE.md](CORE.md) を読む。考え方の核と、この人への手伝い方（頼み方のルール）が書いてある。
2. 相談の内容に関係するものを、下の目次やリポジトリ内検索で探して読む。
3. 出典の段階に注意する。**quote**（原文どおり）、**paraphrase**（言い換え・要検証）、
   **動画要約**（AIによる要約）。本人の文章も n=1 の仮説で、検証済みではない。
4. この人が新しい考えを話したら、`thoughts/` と同じ形（本人の言葉／整理）で持ち帰りメモを作って渡す。
   職場の情報は混ぜない。
