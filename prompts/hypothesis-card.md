# 仮説カード（リーダーが業務の中で小さく試すための1枚）

## 何のために、誰に、いつ、何を材料に

- **ターゲット**: 共有や検討で終わり、変化（対策）が起きないこと。
- **誰が使う**: 各リーダー。1人1枚から始める。
- **いつ**: 試しを始める前に書く。週1回（5分）見返す。終わったら結果を書いて閉じ、次の1枚へ。
- **材料**: 改善テーマ（向き）、失敗・つまずきの記録、聞き取りの記録、自分の違和感。
- **測るもの**: 試しの数と、試した結果として変えたことの数（「変化が起きた回数」）。当たり外れの率ではない。

## 考え方

- テーマは向きを決めるだけ。動くのは仮説と試し。
- 仮説は確信でなくてよい。「たぶんこうだと思う」で書く。
- 試しは、外れても痛くない大きさにする（1〜2週間、自分の担当範囲、元に戻せる）。
- 外れも成果。外れたら、何が違ったかを1行書いて次の仮説に進む。
- 人のせいにしない。仮説は「仕組み・手順・情報の置き場所」の側に置く。

## カード（この形で書く）

```
仮説カード No.__　　リーダー：______　　テーマ：______

1. 気になっていること（事実）：
   例のように、見たこと・数えたことを書く。解釈は書かない。

2. 仮説（たぶん、こうだから）：
   「〇〇が原因で、△△が起きている」の形で1文。

3. 小さな試し（いつ・どこで・何を変える）：
   期間：____〜____（1〜2週間）
   範囲：自分の担当の______
   変えること：1つだけ

4. 当たり・外れの見分け方（試す前に決める）：
   当たりなら：______が見える
   外れなら：______のまま

5. 結果（試した後に書く）：
   起きたこと：
   当たり／外れ／分からない：
   次にすること（続ける・広げる・やめる・別の仮説へ）：
```

## 例（これに限らない）

| 気になっていること | 仮説 | 小さな試し |
|---|---|---|
| 走り出しの2週間、同じ種類の質問が何度も来る | 案件の前提が1か所にまとまっていないから | 次の案件で、初日に1枚の取扱説明書を渡す |
| 追い込み残業が月末に集中する | 見積もりに、顧客の回答待ちの時間が入っていないから | 1件だけ、待ち時間を見積もりに入れて出してみる |
| 追い込み残業の理由がはっきりしない | 理由が記録されていないから、話が印象論になる | 2週間、残業のたびに理由を4つから1つ選んで記録する |
| 新人が提出後の手戻りで時間を取られる | 出す前の検算の基準がないから | 新人1人に、5項目の検算表を1週間使ってもらう |
| 共有しても何も変わらない | 共有の後の「誰が・いつ・何を試すか」が決まっていないから | 次の共有会の最後に、各自1枚の仮説カードを書いて終わる |

## 週1回の見返し（5分）

- 今のカードの試しは進んでいるか。止まっているなら、試しを小さくする。
- 結果が出たカードは、結果を書いて閉じる。
- 閉じたカードは共有の置き場所に1件1ファイルで置く（チームのつまずき記録と同じ場所でよい）。

## 間違っているとしたら、ここ

- カードが「書くこと」自体の負担になると、共有と同じく止まる。最初は項目1〜4だけ、1人1枚から。
- リーダーが試す時間を持てないと回らない。試しは、ふだんの業務のやり方を1つ変える形にし、別の作業を増やさない。
