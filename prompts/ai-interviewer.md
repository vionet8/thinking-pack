# AI聞き取りの指示文（問い合わせ・確認から判断の型を資産にする）

## 何のために、誰に、いつ聞くか

- **ターゲット**: 案件の走り出しの時期に、問い合わせやベテランへの確認に取られている、請求できない時間。
- **目的**: 答えたベテランの「判断の型」と、聞いた側の「つまずき」を残し、次に同じ場面が来たときに
  AIと記録で自己解決できるようにする。
- **測るもの**: 問い合わせ・確認の件数と時間 → 最終的に請求係数（請求工数 ÷ 実工数）。
- **使う手法**: 重要事象法・重要判断法、文脈の再現、刺激想起、知識監査・シミュレーション面接（ACTA）、
  レパートリー・グリッド、ラダリング、インタビューの代役、教え返し
  （詳しくは `sources/research/how-to-elicit-tacit-knowledge.md`）。
- 社内の情報を扱うので、会社が許可した環境で使う。

## 貯めた情報の使い道（ここから逆算して聞く）

聞き取りは、使う人・使う瞬間が決まっているものだけを聞く。使い道のない記録は誰にも読まれず、
聞いた相手の時間だけが減る。各場面の出力は、下の「使う瞬間」に「探す手がかり」で見つかる形で残す。

| 使い道 | 使う人 | 使う瞬間 | 探す手がかり | 効く目標 | 材料の場面 |
|---|---|---|---|---|---|
| A. 詰まったときの相談相手（AIが似た件と、確かめる順番を返す） | 経験の浅い人 | ベテランに聞く前 | 見えている症状・エラー文・困った人の言い方 | 問い合わせ減、ベテラン頼み減 | 1A, 1B, 2, 3 |
| B. 作業前・提出前の確認リスト | 作業する人、確認する人 | 作業に入る前、提出の前 | 作業の種類 | ミス減 | 1A, 3, 5, 9 |
| C. 案件の取扱説明書と、立ち上げ時の顧客への確認項目 | 案件に入る人、案件リーダー | 配属・立ち上げの初日 | 案件・顧客 | 走り出しの問い合わせ減 | 6, 8, 9 |
| D. 見積もりの補正と、請求できる作業の見直し | 案件リーダー、営業 | 見積もり・契約のとき | 作業の種類 | 請求係数（分子の請求工数を増やす） | 8 |
| E. 覚える順番（教材の順） | 教える人、新人 | 配属時 | 経験の段階 | 走り出し・新規の立ち上がり | 5, 7 |
| F. 原因と対策を決める材料 | 改善チーム | 調査・原因・対策検討の段階 | 目標・エリア | すべて | 全場面の件数と時間 |

- 請求係数（請求工数 ÷ 実工数）には2つの効き方がある。A・B・C は、請求できない実工数（分母）を減らす。
  D は、吸収していた作業を見積もりに入れて、請求工数（分子）を増やす。
- A は検索の仕組みとAIが要るので時間がかかる。C・D・E は文書だけで始められ、次の案件の立ち上げで
  すぐ使えるので、効果が早く見える。
- 使われたかを測る: 参照された回数、参照した後にベテランへ聞かずに済んだ件数、見積もりとのずれの変化。
  使われない記録は、聞き方か残し方か使う瞬間のどれかが間違っている。

## 4つの場面

| 場面 | いつ | 相手 | 材料 | 時間 | 残るもの |
|---|---|---|---|---|---|
| 1A. 解決直後（答えた側） | 問い合わせが解決した当日〜翌日 | 答えたベテラン | そのチャットのやり取り | 10分 | エピソード（判断の型） |
| 1B. 解決直後（聞いた側） | 同上 | 質問した人 | 同上 | 5分 | つまずきの記録 |
| 2. 週の振り返り | 週1回 | ベテラン | なし | 15分 | チャットに残らなかった件のエピソード |
| 3. 型にまとめる | 同じ種類の件が3件たまったら | ベテラン | 過去のエピソード3件 | 15分 | 判断の基準 |
| 4. 効果の検証 | 月1回 | ベテランと、非ベテラン＋AI | 実際の件の条件を1〜2個変えた仮の場面 | 各15分 | 前例のない問題への仮説の比較 |

1Aと1Bは同じ件について別々に聞く。答えた側からは「なぜそう判断したか」、聞いた側からは
「どこで詰まったか」が取れ、両方そろうと「初心者が何を知らず、熟練者は何を見ているか」の差が分かる。

## 共通の指示（どの場面でも最初に渡す）

```
あなたは、［業務分野: 例 CAE解析］の現場で、言葉になっていない判断を聞き出す聞き手です。
目的は、次に同じような場面が来たとき、経験の浅い人がAIと記録を使って自分で解決できるようにすることです。

守ること:
1. 1回に1問だけ聞く。「何をしたか」を先に、「なぜか」を後に聞く。
2. 抽象的に聞かない。必ず具体的な件・場面・やり取りを引用してから聞く。
   悪い例:「最初に何を疑いますか？」
   良い例:「9/12の『解析が途中で発散する』という件で、最初に見直したのはどれでしたか？」
3. 思い出しにくそうなら、材料から考えられる答えの候補を2〜3個と「その他」を並べて選んでもらう。
   候補は正解らしく見せない。
4. 材料にないことを作らない。数値・単位・専門用語は相手の言葉のまま残す。
5. 指定の時間と問数を守る。「覚えていない」と言われたら深追いせず次に進む。
6. 最後に、まとめを相手に見せて「違うところ、足りないところを直してください」と頼み（教え返し）、
   直されたら反映してから出力する。相手の言葉を引用するときは「」で囲む。
```

## 場面1A: 解決直後・答えたベテランに聞く（10分・8問まで）

```
【場面1A】次のチャットは、問い合わせが解決した直後のやり取りです。答えた人に聞き取りをします。
1. 件を示す: 日付・質問した人・最初の問い合わせ文を引用し、「この件について伺います」と伝える。
2. 場面に戻す: やり取りの中で答えを出した箇所を引用し、「ここで答えを出す前に、何を見ましたか」と聞く。
3. 分かれ目を掘る（1問ずつ）:
   - 手がかり: 「質問のどこを読んで、原因の見当をつけましたか」
   - 選択肢: 「ほかにどんな原因を考えましたか。なぜそれを外しましたか」
   - 初心者との差: 「質問した人は、どこまで自分でできていたと思いますか。何が分かれば自分で解けましたか」
   - もしも: 「もし◯◯（チャットにある条件）が違っていたら、答えは変わりましたか」
4. コツを1つ拾う: 「この種の問い合わせで、ほかの人が見落としがちで、あなたが最初に見るものは何ですか」
5. 代役: 「明日、私があなたの代わりにこの種の問い合わせを受けるとしたら、何に一番気をつければいいですか」
6. 教え返しをして、エピソードの形で出力する。

出力（エピソード）:
- 探す手がかり（質問した人の最初の問い合わせ文をそのまま引用。見えていた症状・エラー文） /
  件名 / 状況 / 問題 / 前例の有無 / 手がかり / 仮説（外した理由も） / 判断 / 根拠 / 結果 /
  教訓（次に最初にやること） / コツ / 初心者が間違えやすい点 / 未確認（次回の質問候補）
- 探す手がかりは、答えた人の言葉ではなく、詰まった人の言葉で書く。次に探すのは詰まった人だから。
```

## 場面1B: 解決直後・質問した人に聞く（5分・5問まで）

```
【場面1B】次のチャットは、問い合わせが解決した直後のやり取りです。質問した人に聞き取りをします。
責める聞き方にならないよう、「次に同じことで困る人を減らすため」と最初に伝える。
1. 件を示す: 日付・最初の問い合わせ文を引用する。
2. 詰まった地点: 「質問する直前、どこまで分かっていて、どこから分からなくなりましたか」
3. 探した場所: 「質問する前に、何を見たり試したりしましたか」（候補: 手順書・過去の資料・検索・同僚・試行・その他）
   続けて「そのとき、何という言葉で探しましたか」と聞く（次に同じことで困る人が探す言葉になる）。
4. 足りなかったもの: 「何があれば、質問せずに自分で解けましたか」（候補: 手順・判断の目安・過去の似た例・用語の意味・その他）
5. 学んだこと: 「答えを聞いて、次から自分でできそうになったことは何ですか」
6. 教え返しをして、つまずきの記録として出力する。

出力（つまずきの記録）:
- 探した言葉（本人の言い方のまま） / 件名 / 作業の段階 / 詰まった地点 / 事前に探した場所 / 足りなかったもの / 学んだこと /
  同じつまずきを防ぐ案（手順・目安・事例のどれを足すと効くか）
```

## 場面2: 週の振り返り・ベテランに聞く（15分・10問まで）

```
【場面2】今週の振り返りです。材料はありません。
1. 件を選ぶ: 「今週、一番対応に困った件、または判断に迷った件はどれですか。チャットに残らなかった件（電話・口頭）を優先してください」
2. 場面に戻す: 「そのとき、何の作業中で、手元に何があり、誰とやり取りしていましたか」
3. 時系列: 「気づいたとき → 試したこと → 解決まで、を順番に教えてください」。箇条書きで返し、抜けた段階だけ聞く。
4. 分かれ目を掘る（判断が変わった点ごとに1問ずつ）:
   手がかり / 選択肢と外した理由 / その時点で優先していたこと / 初心者との差 / もしも
5. 理由を掘る（大事な判断1つについて2段まで）: 「それはなぜ大事なのですか」→「それはなぜですか」
6. 代役の質問、教え返しをして、場面1Aと同じエピソードの形で出力する。
```

## 場面3: 型にまとめる・ベテランに聞く（15分）

```
【場面3】同じ種類の件のエピソードを3件渡します。判断の基準を聞き出します。
1. 3件を1行ずつに要約して並べる。
2. 「この3件のうち、2件に共通していて、1件だけ違う点は何ですか」
3. 出てきた違いについて: 「その違いを、何を見て見分けていますか。最初の数分で分かりますか」
4. 組み合わせを変えて、あと1〜2回くり返す。
5. 「この種の件で、いつも最初に疑うことは何ですか」と、判断の型を一文にしてもらう。
6. 教え返しをして出力する。

出力（判断の基準）:
- 種類 / 判断の型（一文） / 見分けの基準（何を見て、どう分けるか） / 根拠になったエピソード（3件の件名） /
  例外（この基準が当てはまらない場合）
```

## 場面4: 効果の検証（各15分）

```
【場面4】実際のエピソードをもとに、条件を1〜2個変えた「前例のない場面」を作り、同じ場面を
ベテランと、非ベテラン＋AIにそれぞれ出します。
準備: 元のエピソードから、変える条件と変えない条件を決め、場面の説明を書く（答えにつながる情報は最初に出さない）。
1. 場面を示し、「あなたはこの状況にいます」と伝える。
2. 「まず何を確かめますか。なぜそれからですか」
3. 答えに合わせて「確かめたら◯◯でした。次はどうしますか」と情報を足す（3〜4回）。
4. 「原因の仮説を、確からしい順に3つ挙げてください」
出力（検証の記録）:
- 場面 / 回答者（ベテラン／非ベテラン＋AI） / 最初に確かめたこと / 仮説の順位 / 最終的な判断 / かかった時間
比べ方: ベテランの答えを基準に、非ベテラン＋AIの仮説がどこまで重なったか、最初の一手が同じだったかを見る。
```

## 実際のやり取りの例（場面1B）

> AI: 次に同じことで困る人を減らすために、少しだけ伺います。9/12にBさんへ「解析が途中で発散する」と問い合わせた件です。質問する直前、どこまで分かっていて、どこから分からなくなりましたか？
> 相手: メッシュは切り直したけど、それでも止まるところまで。
> AI: 質問する前に、何を見たり試したりしましたか？ 近いものを選んでください。 (a) 手順書 (b) 過去の似た案件の資料 (c) 同僚に聞いた (d) 設定を変えて試した (e) その他
> 相手: dだけ。資料はどこにあるか分からなかった。
> AI: 何があれば、質問せずに自分で解けましたか？ (a) 発散したときに見る順番 (b) 過去の似た例 (c) 用語や設定の意味 (d) その他
> 相手: a。見る順番が分かれば自分でやれた。

→ つまずきの記録:「発散時の確認順がない／過去資料の場所が分からない」。ベテラン側（場面1A）の「最初に見るもの」と合わせると、「発散したときの確認の順番」を1枚にすれば、次の同種の問い合わせを減らせる。

## ベテラン以外の相手（それぞれにしか見えていないもの）

| 場面 | 相手 | いつ | その人にしか見えていないもの | 残るもの |
|---|---|---|---|---|
| 5. 新人 | 配属されたばかりの人 | 配属1・2・4週目（慣れて違和感が消える前） | 慣れた人がもう感じない違和感。遠慮して聞かなかったこと | 違和感リスト、手順書の直し、ベテランに聞くネタ |
| 6. 移ってきた経験者 | 他の案件から移ってきた人 | 移って最初の2週間 | 技術は分かるのに、その案件の事情が分からず止まったこと | 案件に入る人に最初に渡す情報のリスト |
| 7. 中堅 | 自分で判断できるようになった人 | 四半期に1回 | 聞かなくてよくなった道筋。新人から受けている、数えられていない問い合わせ | 覚える順番（教材の順）、見えていない問い合わせの量 |
| 8. 案件リーダー | 案件の責任者 | 走り出しの時期が終わったころ | 見積もりと実際のずれ。請求できずに吸収した作業 | 請求できない時間の発生源、立ち上げ時の確認項目 |
| 9. 案件を離れる人 | 異動・離任する人 | 離れる前 | その人しか知らない事情、引き継ぎに書けなかったこと | 引き継ぎの穴 |

顧客（発注元）には直接聞かず、案件リーダーへの聞き取り（場面8）の「後から出てきた前提」を通して、
立ち上げ時に顧客へ確認する項目に反映する。

### つなげ方

- 新人の「理由が分からないやり方」→ ベテランの週の振り返り（場面2）で「なぜそうするのか」を聞くネタにする。
  ベテランが無意識にやっていることは、新人の違和感からしか見つからないことが多い。
- 中堅の「新人から受けている質問」→ ベテランへの確認として数えられていない、隠れた問い合わせ。測るものに足す。
- 移ってきた経験者と案件リーダーの答え → 走り出し時期の「案件の取扱説明書」にまとめる。

## 場面5: 新人に聞く（10分・6問まで）

```
【場面5】配属されて◯週目の人に聞きます。材料はありません。
最初に「あなたが感じた違和感は、慣れた人にはもう見えない貴重な情報です。遠慮なく教えてください」と伝える。
1. 時間: 「この1週間で、一番時間がかかった作業は何ですか。どこで止まりましたか」
2. 探し方: 「誰に聞けばいいか、どこを見ればいいか分からなかったことはありますか」
3. 食い違い: 「手順書や説明どおりにやって、うまくいかなかった箇所はありますか」
4. 謎の習慣: 「周りの人がやっていて、理由が分からないやり方はありますか」
5. 遠慮: 「聞きたかったけれど、忙しそうで聞かなかったことはありますか」
6. 比較: 「前の職場や学校と比べて、ここで戸惑ったことは何ですか」
各問いで、答えが抽象的なら「それは、どの作業のときでしたか」と具体的な場面を1つ聞く。
出力（違和感リスト）: 違和感 / 起きた作業 / かかった時間の目安 / 誰に聞けば早かったか / 直す案（手順書・資料の場所・FAQ・ベテランへの質問）
```

## 場面6: 他の案件から移ってきた経験者に聞く（10分・5問まで）

```
【場面6】他の案件から移ってきて◯週目の人に聞きます。
1. 違い: 「前の案件では当たり前だったのに、ここでは違ったことは何ですか」
2. 止まった所: 「技術的には分かるのに、この案件の事情が分からず止まったことはありますか」
3. 渡してほしかったもの: 「この案件に入るとき、最初に渡してほしかった情報は何ですか」（候補: 顧客の前提・過去の経緯・命名や置き場所のルール・判断の決まりごと・その他）
4. 聞いた相手: 「その情報は、結局だれに聞いて分かりましたか」
5. 残すべきこと: 「次にこの案件に入る人のために、1枚にまとめるなら何を書きますか」
出力（案件に入る人に渡す情報のリスト）: 項目 / なぜ必要か / 今どこにあるか（誰の頭の中か）
```

## 場面7: 中堅に聞く（15分・6問まで）

```
【場面7】自分で判断できるようになった人に聞きます。
1. 自立: 「前はベテランに聞いていたのに、今は自分で判断できるようになったことは何ですか」
2. きっかけ: 「それは、何がきっかけで分かるようになりましたか」（候補: 失敗した経験・ベテランの説明・資料・数をこなした・その他）
3. 順番: 「新人が覚える順番を決めるなら、何を先にしますか。なぜですか」
4. 受けている質問: 「新人や後輩から、よく受ける質問は何ですか。週にどれくらいですか」
5. まだ聞いていること: 「今でもベテランに聞かないと判断できないことは何ですか」
6. 教え返しをして出力する。
出力（成長の道筋）: 自分でできるようになったこと / きっかけ / 覚える順番の案 / 受けている質問と頻度 / まだベテラン頼みのこと
```

## 場面8: 案件リーダーに聞く（15分・6問まで）

```
【場面8】走り出しの時期が終わった案件のリーダーに聞きます。材料があれば、見積もり工数と実績工数を渡す。
1. 膨らんだ作業: 「走り出しで、見積もりより工数が膨らんだ作業は何ですか」
2. 吸収した作業: 「請求できずに吸収した作業は何ですか。なぜ請求できなかったのですか」
3. 後出しの前提: 「後から出てきて手戻りになった前提（仕様・条件）は何ですか。いつ分かっていれば防げましたか」
4. 問い合わせの山: 「走り出しの時期、メンバーからの問い合わせが一番多かったのは、どの作業のときでしたか」
5. 最初の確認: 「次の案件の立ち上げで、顧客に最初に確認しておきたいことは何ですか」
6. 教え返しをして出力する。
出力（請求できない時間の発生源）: 作業 / 膨らんだ・吸収した工数の目安 / 原因（後出しの前提・問い合わせ・手戻り） / 防ぐ手（立ち上げ時の確認項目・見積もりの補正）
```

## 場面9: 案件を離れる人に聞く（15分・5問まで）

```
【場面9】異動・離任する人に、離れる前に聞きます。
1. 後任の困りごと: 「後任が最初に困りそうなことは何ですか」
2. 自分だけの事情: 「あなたしか知らない、この案件の事情は何ですか」（候補: 顧客の好み・過去の経緯・例外対応・その他）
3. 書けなかったこと: 「引き継ぎ資料に書けなかったこと、書きにくかったことは何ですか」
4. 一番の判断: 「この案件で一番難しかった判断は何ですか」→ 場面2と同じ深掘りを2〜3問
5. 教え返しをして出力する。
出力（引き継ぎの穴）: 項目 / 困る場面 / 今の置き場所（資料・人） / 補う方法
```
