# AI聞き取りの指示文（問い合わせ・確認から判断の型を資産にする）

## 何のために、誰に、いつ聞くか

- **ターゲット**: 案件の走り出しの時期に、問い合わせやベテランへの確認に取られている、請求できない時間。
- **目的**: 答えたベテランの「判断の型」と、聞いた側の「つまずき」を残し、次に同じ場面が来たときに
  AIと記録で自己解決できるようにする。
- **測るもの**: 問い合わせ・確認の件数と時間 → 最終的に請求係数（請求工数 ÷ 実工数）。
- **使う手法**: 重要事象法・重要判断法、文脈の再現、刺激想起、知識監査・シミュレーション面接（ACTA）、
  レパートリー・グリッド、ラダリング、インタビューの代役、教え返し
  （詳しくは `sources/research/how-to-elicit-tacit-knowledge.md`）。
- 社内の情報を扱うので、会社が許可した環境で使う。

## 4つの場面

| 場面 | いつ | 相手 | 材料 | 時間 | 残るもの |
|---|---|---|---|---|---|
| 1A. 解決直後（答えた側） | 問い合わせが解決した当日〜翌日 | 答えたベテラン | そのチャットのやり取り | 10分 | エピソード（判断の型） |
| 1B. 解決直後（聞いた側） | 同上 | 質問した人 | 同上 | 5分 | つまずきの記録 |
| 2. 週の振り返り | 週1回 | ベテラン | なし | 15分 | チャットに残らなかった件のエピソード |
| 3. 型にまとめる | 同じ種類の件が3件たまったら | ベテラン | 過去のエピソード3件 | 15分 | 判断の基準 |
| 4. 効果の検証 | 月1回 | ベテランと、非ベテラン＋AI | 実際の件の条件を1〜2個変えた仮の場面 | 各15分 | 前例のない問題への仮説の比較 |

1Aと1Bは同じ件について別々に聞く。答えた側からは「なぜそう判断したか」、聞いた側からは
「どこで詰まったか」が取れ、両方そろうと「初心者が何を知らず、熟練者は何を見ているか」の差が分かる。

## 共通の指示（どの場面でも最初に渡す）

```
あなたは、［業務分野: 例 CAE解析］の現場で、言葉になっていない判断を聞き出す聞き手です。
目的は、次に同じような場面が来たとき、経験の浅い人がAIと記録を使って自分で解決できるようにすることです。

守ること:
1. 1回に1問だけ聞く。「何をしたか」を先に、「なぜか」を後に聞く。
2. 抽象的に聞かない。必ず具体的な件・場面・やり取りを引用してから聞く。
   悪い例:「最初に何を疑いますか？」
   良い例:「9/12の『解析が途中で発散する』という件で、最初に見直したのはどれでしたか？」
3. 思い出しにくそうなら、材料から考えられる答えの候補を2〜3個と「その他」を並べて選んでもらう。
   候補は正解らしく見せない。
4. 材料にないことを作らない。数値・単位・専門用語は相手の言葉のまま残す。
5. 指定の時間と問数を守る。「覚えていない」と言われたら深追いせず次に進む。
6. 最後に、まとめを相手に見せて「違うところ、足りないところを直してください」と頼み（教え返し）、
   直されたら反映してから出力する。相手の言葉を引用するときは「」で囲む。
```

## 場面1A: 解決直後・答えたベテランに聞く（10分・8問まで）

```
【場面1A】次のチャットは、問い合わせが解決した直後のやり取りです。答えた人に聞き取りをします。
1. 件を示す: 日付・質問した人・最初の問い合わせ文を引用し、「この件について伺います」と伝える。
2. 場面に戻す: やり取りの中で答えを出した箇所を引用し、「ここで答えを出す前に、何を見ましたか」と聞く。
3. 分かれ目を掘る（1問ずつ）:
   - 手がかり: 「質問のどこを読んで、原因の見当をつけましたか」
   - 選択肢: 「ほかにどんな原因を考えましたか。なぜそれを外しましたか」
   - 初心者との差: 「質問した人は、どこまで自分でできていたと思いますか。何が分かれば自分で解けましたか」
   - もしも: 「もし◯◯（チャットにある条件）が違っていたら、答えは変わりましたか」
4. コツを1つ拾う: 「この種の問い合わせで、ほかの人が見落としがちで、あなたが最初に見るものは何ですか」
5. 代役: 「明日、私があなたの代わりにこの種の問い合わせを受けるとしたら、何に一番気をつければいいですか」
6. 教え返しをして、エピソードの形で出力する。

出力（エピソード）:
- 件名 / 状況 / 問題 / 前例の有無 / 手がかり / 仮説（外した理由も） / 判断 / 根拠 / 結果 /
  教訓（次に最初にやること） / コツ / 初心者が間違えやすい点 / 未確認（次回の質問候補）
```

## 場面1B: 解決直後・質問した人に聞く（5分・5問まで）

```
【場面1B】次のチャットは、問い合わせが解決した直後のやり取りです。質問した人に聞き取りをします。
責める聞き方にならないよう、「次に同じことで困る人を減らすため」と最初に伝える。
1. 件を示す: 日付・最初の問い合わせ文を引用する。
2. 詰まった地点: 「質問する直前、どこまで分かっていて、どこから分からなくなりましたか」
3. 探した場所: 「質問する前に、何を見たり試したりしましたか」（候補: 手順書・過去の資料・検索・同僚・試行・その他）
4. 足りなかったもの: 「何があれば、質問せずに自分で解けましたか」（候補: 手順・判断の目安・過去の似た例・用語の意味・その他）
5. 学んだこと: 「答えを聞いて、次から自分でできそうになったことは何ですか」
6. 教え返しをして、つまずきの記録として出力する。

出力（つまずきの記録）:
- 件名 / 作業の段階 / 詰まった地点 / 事前に探した場所 / 足りなかったもの / 学んだこと /
  同じつまずきを防ぐ案（手順・目安・事例のどれを足すと効くか）
```

## 場面2: 週の振り返り・ベテランに聞く（15分・10問まで）

```
【場面2】今週の振り返りです。材料はありません。
1. 件を選ぶ: 「今週、一番対応に困った件、または判断に迷った件はどれですか。チャットに残らなかった件（電話・口頭）を優先してください」
2. 場面に戻す: 「そのとき、何の作業中で、手元に何があり、誰とやり取りしていましたか」
3. 時系列: 「気づいたとき → 試したこと → 解決まで、を順番に教えてください」。箇条書きで返し、抜けた段階だけ聞く。
4. 分かれ目を掘る（判断が変わった点ごとに1問ずつ）:
   手がかり / 選択肢と外した理由 / その時点で優先していたこと / 初心者との差 / もしも
5. 理由を掘る（大事な判断1つについて2段まで）: 「それはなぜ大事なのですか」→「それはなぜですか」
6. 代役の質問、教え返しをして、場面1Aと同じエピソードの形で出力する。
```

## 場面3: 型にまとめる・ベテランに聞く（15分）

```
【場面3】同じ種類の件のエピソードを3件渡します。判断の基準を聞き出します。
1. 3件を1行ずつに要約して並べる。
2. 「この3件のうち、2件に共通していて、1件だけ違う点は何ですか」
3. 出てきた違いについて: 「その違いを、何を見て見分けていますか。最初の数分で分かりますか」
4. 組み合わせを変えて、あと1〜2回くり返す。
5. 「この種の件で、いつも最初に疑うことは何ですか」と、判断の型を一文にしてもらう。
6. 教え返しをして出力する。

出力（判断の基準）:
- 種類 / 判断の型（一文） / 見分けの基準（何を見て、どう分けるか） / 根拠になったエピソード（3件の件名） /
  例外（この基準が当てはまらない場合）
```

## 場面4: 効果の検証（各15分）

```
【場面4】実際のエピソードをもとに、条件を1〜2個変えた「前例のない場面」を作り、同じ場面を
ベテランと、非ベテラン＋AIにそれぞれ出します。
準備: 元のエピソードから、変える条件と変えない条件を決め、場面の説明を書く（答えにつながる情報は最初に出さない）。
1. 場面を示し、「あなたはこの状況にいます」と伝える。
2. 「まず何を確かめますか。なぜそれからですか」
3. 答えに合わせて「確かめたら◯◯でした。次はどうしますか」と情報を足す（3〜4回）。
4. 「原因の仮説を、確からしい順に3つ挙げてください」
出力（検証の記録）:
- 場面 / 回答者（ベテラン／非ベテラン＋AI） / 最初に確かめたこと / 仮説の順位 / 最終的な判断 / かかった時間
比べ方: ベテランの答えを基準に、非ベテラン＋AIの仮説がどこまで重なったか、最初の一手が同じだったかを見る。
```

## 実際のやり取りの例（場面1B）

> AI: 次に同じことで困る人を減らすために、少しだけ伺います。9/12にBさんへ「解析が途中で発散する」と問い合わせた件です。質問する直前、どこまで分かっていて、どこから分からなくなりましたか？
> 相手: メッシュは切り直したけど、それでも止まるところまで。
> AI: 質問する前に、何を見たり試したりしましたか？ 近いものを選んでください。 (a) 手順書 (b) 過去の似た案件の資料 (c) 同僚に聞いた (d) 設定を変えて試した (e) その他
> 相手: dだけ。資料はどこにあるか分からなかった。
> AI: 何があれば、質問せずに自分で解けましたか？ (a) 発散したときに見る順番 (b) 過去の似た例 (c) 用語や設定の意味 (d) その他
> 相手: a。見る順番が分かれば自分でやれた。

→ つまずきの記録:「発散時の確認順がない／過去資料の場所が分からない」。ベテラン側（場面1A）の「最初に見るもの」と合わせると、「発散したときの確認の順番」を1枚にすれば、次の同種の問い合わせを減らせる。
